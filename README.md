## 📌 Objective
The objective of this project is to analyze transaction data using statistical distributions and understand customer behavior through probability and data analysis techniques.

---

## 📂 Dataset
The dataset represents an e-commerce transaction system and includes:

- transaction_id  
- customer_id  
- transaction_amount  
- transaction_date  
- transaction_count  
- region  
- transaction_status  

---

## ⚙️ Techniques Used
- Bernoulli Distribution  
- Binomial Distribution  
- Poisson Distribution  
- Log-Normal Distribution  
- Power Law Distribution  
- Q-Q Plot  
- Box-Cox Transformation  
- Z-score Analysis  
- PDF & CDF  

---

## 📊 Key Insights
- Transaction data is right-skewed  
- Log-Normal distribution fits better than Normal  
- High-value transactions are rare  
- Box-Cox transformation improves data normality  
- Poisson distribution models transaction counts effectively
